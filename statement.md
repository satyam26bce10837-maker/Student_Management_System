# Project Statement

## Problem Statement

Managing student academic information using separate files or manual
records can make it difficult to organize student details, marks, and
attendance in one place.

The Student Productivity & Academic Management System provides a
simple Python-based console application for managing these academic
records in an organized manner.

The system allows users to maintain student information, manage subjects
and marks, record attendance, calculate academic results, and generate a
consolidated academic report.

## Project Scope

The project focuses on basic academic record management through a
console-based Python application.

The current scope includes:

- Student information management
- Subject and marks management
- Attendance management
- Academic result calculation
- Academic report generation
- JSON-based data storage
- Input validation and error handling

The project does not currently include a graphical user interface or
database system.

## Target Users

The system is intended for:

- Students who want to maintain their academic records
- Beginners learning Python programming
- Academic project evaluators who want to understand the working of a
  modular Python application

## High-Level Features

### Student Management

Allows users to add, view, update, and delete student information.

### Subjects and Marks

Allows users to manage subjects and marks and calculate total marks,
percentage, and grade.

### Attendance Management

Allows users to record attendance and calculate attendance percentage.
The system also displays a warning when attendance is below 75%.

### Academic Reports

Generates a consolidated report containing student information, subjects
and marks, academic result, and attendance.

### Data Storage

Stores application data in JSON files so that information remains
available after the program is closed.

## Project Objective

The main objective of this project is to develop a simple and modular
Python application that demonstrates practical use of Python
programming concepts such as functions, modules, lists, dictionaries,
file handling, JSON, validation, and exception handling.
